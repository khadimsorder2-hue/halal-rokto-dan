## 🏗️ প্রযুক্তি

- **১০০% নেটিভ Java** — কোনো WebView, কোনো HTML/JS, কোনো ফ্রেমওয়ার্ক নেই
- **নেটিভ ডিজাইন সিস্টেম**: `D.java` — Material 3 টোকেন (লাইট+ডার্ক), RippleDrawable, GradientDrawable
- **কম্পোনেন্ট লাইব্রেরি**: `Ui.java` — হিরো অ্যাপবার, বাটন, ফিল্ড, বটম শিট, টোস্ট
- **কাস্টম Canvas ভিউ**: `Views.java` — কুলডাউন রিং (SweepGradient), যাচাই প্যাটার্ন, পালস ডট
- **৪২টি ভেক্টর আইকন** (Material Symbols → VectorDrawable)
- **Noto Sans Bengali** ৪ ওয়েট (400/500/600/700) — `res/font/`
- **ডেটা**: অফলাইন-প্রথম (SharedPreferences + org.json), ডেমো সীড ডেটাসহ
- **বিল্ড**: ম্যানুয়াল টুলচেইন — aapt2 → javac → d8 → zipalign → apksigner (Gradle ছাড়া!)
